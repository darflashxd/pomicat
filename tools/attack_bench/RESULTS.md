# Attack bench: recovering a hidden salary from a redacted AI chat

40 fictional English chats (`--lang en`), fixed seed; each states a salary and the assistant replies with figures derived from it. Generated by `tools/attack_bench/run.js`. Replies are templated, not real model output.

## Arithmetic attacker (rule-based)

| Redactor | Attacker | Salary left visible | Recovered from the rest | Total leaked |
|---|---|---|---|---|
| none | arithmetic | 100% | 0% | **100%** |
| naive | arithmetic | 0% | 53% | **53%** |
| presidio | arithmetic | 100% | 0% | **100%** |
| pomicat | arithmetic | 0% | 0% | **0%** |

## LLM attacker (DeepSeek V4 Pro via OpenCode CLI)

| Redactor | Attacker | Salary left visible | Recovered from the rest | Total leaked |
|---|---|---|---|---|
| naive | llm:9router/ds/deepseek-v4-pro | 0% | 100% | **100%** |
| presidio | llm:9router/ds/deepseek-v4-pro | 100% | 0% | **100%** |
| pomicat | llm:9router/ds/deepseek-v4-pro | 0% | 0% | **0%** |

Recovered = the attacker's answer is within 1% of the true salary. "Visible" = the redactor didn't hide the salary at all.

Readable report, method and per-case transcript: `tools/attack_bench/RESULTS_LLM.md`. One attacker model only; Presidio's default recognizers don't cover financial amounts, so it leaves salaries visible.
