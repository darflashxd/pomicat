================================================================================
          SAFESHARE-AI: PANDUAN CEPAT PENGGUNAAN (UNTUK SEMUA ORANG)
================================================================================

SafeShare-AI adalah ekstensi pelindung privasi obrolan AI (Zero-Knowledge).
Ekstensi ini otomatis menyensor PII, nama lengkap, alamat fisik, gaji pribadi, 
hutang, resep medis, shell terminal, dan API key sebelum link share dibuat.

FITUR UTAMA:
✓ 0% Ketergantungan Laptop: Pengirim bisa langsung mematikan laptopnya!
✓ 100% Kebal Mesin Pencari Google: Kunci enkripsi ada di hash (#).
✓ Tenggat Waktu 24 Jam: Otomatis kedaluwarsa dan terkunci setelah 24 jam.
✓ Universal 1-Click Continue: Penerima bisa langsung melanjutkan obrolan di 
  akun ChatGPT / Claude miliknya sendiri dengan 1 klik.

--------------------------------------------------------------------------------
CARA PASANG DI GOOGLE CHROME / BRAVE / EDGE:
--------------------------------------------------------------------------------
1. Ekstrak (unzip) file SafeShare-AI-Extension.zip ke folder mana saja.
2. Buka browser Chrome / Brave / Edge.
3. Di kolom URL, ketik: chrome://extensions (atau brave://extensions).
4. Aktifkan sakelar "Developer mode" (Mode Pengembang) di pojok kanan atas.
5. Klik tombol "Load unpacked" (Muat yang belum dibongkar) di pojok kiri atas.
6. Pilih folder hasil ekstrak tadi.
7. Selesai! Ekstensi langsung aktif.

--------------------------------------------------------------------------------
CARA PASANG DI MOZILLA FIREFOX:
--------------------------------------------------------------------------------
1. Ekstrak (unzip) file SafeShare-AI-Extension.zip ke folder mana saja.
2. Buka browser Firefox.
3. Di kolom URL, ketik: about:debugging#/runtime/this-firefox
4. Klik tombol "Load Temporary Add-on..." (Muat Pengaya Sementara...).
5. Pilih file "manifest.json".
6. Selesai!

--------------------------------------------------------------------------------
CARA PENGGUNAAN DI CHATGPT / CLAUDE:
--------------------------------------------------------------------------------
1. Buka https://chatgpt.com atau https://claude.ai
2. Lakukan chat seperti biasa (atau buka obrolan yang sudah ada).
3. Klik tombol melayang "🛡️ SafeShare (ZK)" di pojok kanan bawah layar.
4. Periksa pratinjau data: nama Anda, alamat, gaji, dan rahasia disensor otomatis.
5. Klik "Generate ZK Share Link 🚀" dan klik "Copy Link".
6. Bagikan link tersebut ke teman di WhatsApp, Discord, atau Telegram.
7. ANDA BISA LANGSUNG MATIKAN LAPTOP ANDA DETIK ITU JUGA!
   Teman Anda tetap bisa membuka dan membaca obrolan bersih tersebut di HP-nya.
